# Частые вопросы

### Ничего не докачивается, ядро уже внутри?

Да. `sing-box.exe` и `wintun.dll` лежат в установщике, `.so` ядра — в APK. Первый запуск
распаковывает их в пользовательский каталог и запускает оттуда.

### Нужны ли права администратора на Windows?

Для TUN-режима — да: драйвер Wintun устанавливается только с повышением прав. Без них
приложение работает в режиме системного прокси (браузер и большинство программ — через VPN,
но не всё). SHUZU не требует постоянных прав: UAC спрашивается один раз при подключении в TUN.

### У меня не работает ни один VPN на ноутбуке, хотя на телефоне тот же сервер работает

Откройте **Ещё → Диагностика**. Наиболее частые причины именно для ПК:

1. **Остатки другого VPN.** TAP/TUN-адаптеры от OpenVPN, WARP или прошлых клиентов ломают
   маршрутизацию. Диагностика покажет «Другие VPN-адаптеры», лечится удалением в
   «Диспетчере устройств».
2. **Wintun не установился** (антивирус блокирует установку драйвера). Проверка «Wintun».
3. **Сломанный DNS или hosts** после «оптимизаторов».
4. **Прокси в системе** остался от старого клиента — браузер ходит мимо туннеля.
5. **MTU**: при раздаче с телефона (NAT/CGNAT) большие пакеты режутся — поставьте MTU 1380.
6. **Часы**: расхождение больше 2 минут ломает TLS, и ни один сервер не отвечает.

Если телефон раздаёт интернет, а ноутбук — нет, попробуйте в режиме модема включить
«Совместимость»/USB-тетеринг: некоторые операторы режут UDP в раздаче, тогда помогает
только TCP-транспорт (ws/grpc) или Hysteria2 over TCP.

### Работает только ВК, Госуслуги и Яндекс — это блокировка?

Запустите **Проверку блокировок**: она сравнивает локальные и глобальные сервисы.
Если открыты только локальные, а Google/Cloudflare/Telegram не отвечают — трафик фильтрует
провайдер. Если открыто всё — фильтрации нет, ищите проблему на стороне сервера.

### Как включить «белые списки»?

Настройки → «Белые списки (РФ напрямую)». Тогда российские сервисы (банки, госуслуги,
маркетплейсы, операторы) идут напрямую, остальное — через туннель. Список исключений
редактируется рядом, по одному домену в строке.

### Будет ли расход батареи на телефоне?

Служба использует `IMPORTANCE_LOW`, не держит wake-lock и не опрашивает сеть чаще раза
в 2 секунды. Настройки обновления подписок можно отключить. Если система всё равно
выгружает VPN — разрешите работу в фоне (в диагностике есть кнопка).

### Почему SmartScreen ругается на установщик?

Подпись кода не настроена (сертификат стоит денег и требует юрлица). Сборка воспроизводима
из этого репозитория: `npm ci && npm run cores && npm run dist:win`.

### Как перенести подписки на другое устройство?

«Ещё → Профиль → Экспорт настроек» — получите JSON. На другом устройстве «Импорт» и вставьте.
Файл содержит ссылки подписок: обращайтесь с ним как с паролем.

### Где хранятся данные?

Windows: `%APPDATA%/SHUZU`. Android: приватный каталог приложения (`files/`, `SharedPreferences`
через WebView local storage). Ничего не отправляется наружу, кроме запросов к вашим же
подпискам, GitHub (обновления) и целям диагностики.
