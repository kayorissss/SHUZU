# Подпись и обновления без потери данных

## Android

Постоянный applicationId: `com.shuzu.app`. Для установки обновления поверх старой
версии нужны тот же сертификат подписи и больший versionCode. Версия задаётся
в package.json; используйте возрастающие версии X.Y.Z, где Y и Z от 0 до 99.
Не меняйте Capacitor hostname/scheme: настройки хранятся в localStorage WebView.
Не удаляйте приложение перед обновлением. Очистка данных и удаление приложения
удаляют локальные настройки; заранее экспортируйте резервную копию через интерфейс.

Публичные APK никогда не подписываются временным debug-ключом. Без release-ключа
сборка должна завершиться ошибкой. Debug-приложение имеет другой ID (`.debug`).

### Настройка GitHub Actions

Откройте репозиторий → Settings → Secrets and variables → Actions → New repository secret.
Создайте четыре секрета:

- `ANDROID_KEYSTORE_BASE64`: base64-содержимое постоянного PKCS12/JKS-файла.
- `ANDROID_KEYSTORE_PASSWORD`: пароль хранилища.
- `ANDROID_KEY_ALIAS`: `shuzu` для созданного в этой сессии ключа.
- `ANDROID_KEY_PASSWORD`: тот же пароль для PKCS12.

В этой сессии постоянный ключ создан в игнорируемой папке `.signing/`:
`shuzu-release.p12`, `password.txt`, `ANDROID_KEYSTORE_BASE64.txt`.
Эти файлы НЕ входят в Git и не передаются в PR. Сохраните их отдельно в безопасном
месте (пароль — в менеджере паролей). Не публикуйте их в issues, логах и переписке.
GitHub Secrets не являются резервной копией: их значения нельзя скачать обратно.

Публичный SHA-256 отпечаток созданного сертификата:
`31:FD:24:27:77:30:D3:77:C8:89:66:69:C7:E1:C0:5E:C6:E5:B5:80:48:36:AB:73:9F:67:C8:27:0D:66:74:D4`.

Для локальной сборки создайте игнорируемый `android/keystore.properties`:

```properties
storeFile=app/shuzu-release.keystore
storePassword=YOUR_LOCAL_PASSWORD
keyAlias=shuzu
keyPassword=YOUR_LOCAL_PASSWORD
```

Скопируйте постоянный PKCS12 в `android/app/shuzu-release.keystore`.
Путь storeFile считается относительно папки android. Нужен JDK 17.

## Windows

Сертификат Authenticode подтверждает издателя, но не отвечает за сохранение данных.
Пока платного сертификата нет, установщик неподписанный; SmartScreen может показать
предупреждение. Самоподписанный сертификат не устраняет такое предупреждение у пользователей.

Не меняйте appId (`com.shuzu.app`), имя пакета (`shuzu`), productName (`SHUZU`) и
каталог Electron userData. Настройки хранятся отдельно от установленных файлов.
Установщик NSIS настроен с `deleteAppDataOnUninstall: false`.
Перед публичным выпуском нужно проверить обновление N → N+1 на реальных Android
и Windows: импортировать подписку, изменить настройки, установить новую версию
поверх старой и убедиться, что данные сохранились. Это ещё не проверено на устройствах.
